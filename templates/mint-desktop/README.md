# Rusty Penguin Desktop Template

Standalone visual prototype for a polished Rusty Penguin desktop.

Open `index.html` in a browser. This does not touch the real bare-metal
desktop implementation; it is a frontend reference for layout, styling, and
expected desktop workflows.

Included apps:

- Launcher/search
- Terminal
- Text editor
- File navigator
- Process monitor
- Settings
- Browser
